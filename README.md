# 🏦 Mini Smart ATM System

A lightweight, interactive Command Line Interface (CLI) application built in Python that simulates standard Banking/ATM transactions.

## Key Features

* **User Authentication & Security:** Account login requiring user ID and PIN validation with a maximum 3-attempt lock safeguard.
* **Account Registration:** Interactive creation of new user profiles with unique IDs and custom PINs.
* **Core Financial Operations:** Real-time account balance checks, cash deposits, and withdrawals with validation controls (insufficient funds / invalid amounts).
* **Smart Security Alerts:** Basic anomaly detection triggering warnings for high-value withdrawal attempts (>50% of available balance).
* **Receipt Generation & History:** Instant transaction receipts showing transaction type, amount, and remaining balance, alongside logging for the last 5 transactions.

## Technologies Used

* **Language:** Python 3.x
* **Data Handling:** In-memory Python dictionaries and data structures
